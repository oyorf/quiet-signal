# 明确禁止的报告做法

这些禁令来自本轮长篇报告审核，应作为生成和视觉检查的失败条件。

## 排版失败

- 底部补充组件同时拥有顶线和下边线，紧邻页脚顶线形成两条相邻分隔线。
- 主正文小于 `10pt`，或副内容、图注、表格说明和底部信息小于 `8.5pt`。
- 只有视觉对称、没有语义并列依据的双栏；左右长度、层级或阅读起点明显失衡。
- 将几句短内容塞进巨大卡片、表格或矩阵，留下无法解释的空洞空间。
- 补充说明、阅读建议或一句话结论出现在主阅读流中间，迫使读者跳读。
- 全文重复相同卡片网格，页面只换文字，不随内容关系变化。
- 通过缩小字号、压缩行高或隐藏溢出来解决内容过多。

## 内容失败

- 出现内部制作话术，例如“为什么不画这图”“为了统一版式”“本页不展示”“制作环境受限”。
- 添加没有信息增量的解释条，只说明设计选择或复述旁边内容。
- 把长篇说明压缩为连续金句、摘要卡或小红书式结论，删掉方法、因果、限制和证据差异。
- 把编辑推断写成论文结论，或把模型发现写成真实现场测量。
- 没有数据却绘制带坐标、比例、精确数值或趋势的伪图表。
- 使用装饰图片替代证据，或不记录图片来源。

## 视觉失败

- 大面积渐变、发光、玻璃拟态、过度圆角和装饰色抢夺报告内容。
- 不必要的横线、边框和卡片嵌套形成视觉噪声。
- 页底内容随正文漂移，导致来源、页码、补充层无法形成稳定系统。
- 只检查 HTML 或 PDF 文件是否生成，不渲染全页 PNG 和总览图就宣称完成。

这些禁令不要求每个报告复刻示例风格细节；它们约束的是可读性、证据诚实和生产验收。
