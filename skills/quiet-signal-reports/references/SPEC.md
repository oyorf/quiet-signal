# Quiet Signal 长篇报告媒介规范

本规范补充同级 `quiet-signal-design` Skill 中的 `references/SPEC.md`。它只定义 A4 长篇 PDF 报告的内容、排版与验收边界；核心品牌语言仍以基座规范为准。

## 1. 成品与源文件

- 成品是可阅读、可引用、可打印的 PDF；HTML/CSS 是可编辑的排版源，不是需要发布的网站。
- 默认使用 A4 竖版。每页 HTML 容器为 `.page`，宽 `210mm`、高 `297mm`，打印时关闭浏览器页眉页脚并保留背景。
- PDF 正文必须可选择。图像、图示和装饰不得把正文栅格化。
- 每个项目至少交付 HTML、CSS、本地资源、来源账本、PDF、全页 PNG 和总览图。

## 2. 内容优先级

- 先写完整内容，再排版。长篇报告需要交代问题、证据、方法、推理、限制、来源与结论，不得压缩成小红书式提炼、连续金句或卡片摘要。
- 允许删去重复内容、内部制作说明和没有信息增量的解释；不得删掉理解结论所需的因果、限定条件、证据差异或方法说明。
- 区分事实、论文结论、机构解读、模型推断与编辑判断。证据不足时写研究边界，不得伪造确定性。
- 任何具体数据、论文结论、图片和关键判断都要能回到来源账本；页内使用稳定的来源编号。

## 3. 阅读流与页面关系

- 每页只有一个明显的主阅读轴。默认连续单栏；只有信息确实并列、相互比较或具有同等证据重量时才使用双栏或矩阵。
- 双栏必须有清楚的共同起点、对齐关系和阅读顺序。禁止为了填满页面制造左右不对称、长度悬殊或互不相关的两栏。
- 页面结构随内容变化，可使用连续论述、顺序问题、图文解释、条件表、真实比较、证据照片、概念阶梯或结论页；不得把同一套卡片网格复制到全文。
- 空白用于建立节奏和层级，不得用巨大空心组件包裹一两句短内容。

## 4. 字号与可读性

- 主体正文计算字号不得小于 `10pt`，建议基线 `10.25pt`，行高约 `1.55–1.75`。
- 副内容、图注、表格解释、卡片说明和底部补充文字不得小于 `8.5pt`。
- 页眉、来源编号、页码和纯元数据不得小于 `7.5pt`；它们不能承担理解正文所必需的信息。
- 标题与正文必须形成清楚的比例，不以全页超大标题换取稀薄内容，也不通过缩小文字解决溢出。
- 默认左右页边距约 `16–18mm`；正文行长以持续阅读舒适为准。

## 5. 底部系统与分隔线

- 阅读建议、一句话结论、研究优先级、政策提示等补充层放在页脚上方的固定底部区域，不插入主阅读流中间。
- 底部补充层只保留承担语义的紫色顶线；组件自身不得再画下边线。页脚拥有独立的一条灰色顶线。两者之间必须有可辨识间距，禁止形成相邻重复线。
- 页脚包含来源、页码和必要元数据，保持位置稳定。页脚不得承载新的正文论证。
- 最后一页的参考文献和术语表置于结论之后的页面底部系统，不悬浮在正文中间。

## 6. 图、表与图片

- 图示必须解释真实机制、顺序、空间、比较或数据。没有足够数据时使用诚实的概念图、条件表或文字说明，不伪造坐标、精度、比例或趋势。
- 图片要有证据、场景、尺度或节奏作用；注明来源和必要说明。禁止纯装饰图库替代内容。
- 表格适合稳定字段与逐项比较；句子较长、关系不平行或证据不同级时改用连续文字。
- 解释条只有在提供新的判断、限制或行动信息时才存在；“为什么这样排”“为了视觉统一”等制作说明一律删除。

## 7. 成品禁语

成品中禁止出现内部制作话术，包括但不限于：“为什么不画这图”“本报告选择不展示”“为了视觉统一”“长报告保留留白”“制作环境受限”“此处用于说明版式”。需要表达的真实边界必须改写为研究边界、数据缺口或方法限制。

## 8. 渲染与验收

1. 等待网页字体和本地图片加载完成。
2. 检查 `.page` 数量是否符合预期，并检查每一页的横向与纵向溢出。
3. 导出 A4 PDF，确认页数、可选文字、无空白尾页、无裁切。
4. 将 PDF 的每一页渲染为 PNG，并生成总览图。
5. 先检查总览中的节奏、重复构图和异常空白，再全尺寸检查密集正文、表格、图片、底部补充层与参考文献页。
6. 任一页存在小字、错误阅读流、伪图表、内部话术、重复线或溢出时，回到 HTML/CSS 修正并重新导出。
