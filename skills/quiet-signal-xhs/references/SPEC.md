# Quiet Signal · 小红书 Kit

- 版本：`0.1.0`
- 当前发布尺寸：`1080 × 1440`（`3:4`）
- 确认日期：`2026-08-23`

本规范定义 Quiet Signal 在小红书图文中的必要内容整理、页面表达与版面验收。它直接处理当前收到的材料，不规定外部 Agent 如何协作，也不要求调用方预先完成固定流程。Quiet Signal Core 是视觉底层；本规范只补充媒介规则，不反向修改 Core。

## 输入处理边界

只判断当前输入处于什么状态，并完成产出所必需的处理：

- 用户已经给出页序、分页或每页内容时，尊重这些决定，直接进入页面表达；
- 输入是一段文字、文章、网页或其他未分页材料时，先理解主旨、提取有效信息、识别内容关系，再拆成适合连续阅读的页面；
- 用户只锁定标题、页数或部分页面时，只处理未锁定部分，不静默改动已确认决定。

内容处理保持轻量：不规定外部 Agent 分工，不要求复杂流程或中间文件，不把原材料扩写成另一篇文章；保留事实、限定条件、来源与用户要求；分页以语义完整和单页可读为依据，不为套版式强行切断内容。

## 内容与页面

### 1. 每页先有一个明确任务

如果输入尚未分页，先识别每页要完成的判断、问题或任务；如果用户已经分页，则读取每页既定任务。标题优先承担结论或判断，而不只是章节名称。

### 2. 内容关系决定表达方式

页面结构从内容中产生，例如：

- 路线、流程与阶段：路径、节点或时间线；
- 多种选择：比较、筛选或决策条件；
- 机制与因果：步骤、连接与前后关系；
- 事实与证据：数据、原始材料、来源和解释；
- 准备事项：清单、分组或嵌套关系；
- 风险与限制：提高判断边界的对比度；
- 单个对象或地点：让图片承担对象或现场证据，文字负责解释。

这些是关系类型，不是固定模板。新内容可以产生新的结构。

### 3. 每块面积都要由内容挣得

- 长内容可以形成较大的信息区；短标签只能占紧凑区域。
- 图片大小取决于叙事作用，而不是预设框。
- 标题、数字、色块和容器的视觉重量应与信息重要性相称。
- 留白可以承担停顿、聚焦、章节转场或图片呼吸；未分配的剩余空间不是设计。

### 4. 固定画布要有收束

不能把内容横向铺在上半部，再把下半部遗留为空白。页面应形成完整阅读路径，并在底部得到视觉收束。必要时改为纵向信息流、调整图片比例或位置、重组先后与分组；用户未锁定分页时，也可以合并过碎内容或拆分过多内容。

目标不是填满角落，而是避免没有任务的剩余空间。

### 5. 图片必须有角色

图片至少承担对象、证据、环境、路径说明或情绪转场中的一种。图片与说明应直接关联；裁切、尺寸和位置服从其角色。需要居中时，必须在最终画面中实现几何居中或基于主体的光学居中，不能只看外层容器参数。

### 6. 统一来自视觉语言，不来自重复版式

统一感来自近白纸面、黑灰文字层级、少量紫色语义强调、细线、来源与页码系统。页面结构可以随内容变化，但字体层级、颜色职责、边距逻辑、来源标注和页序系统应稳定。

### 7. 整组要有内容驱动的节奏

可在文字页与图片页、密集解释与简洁结论、常规页与高对比风险页、展开说明与阶段性检查之间形成节奏。变化必须由内容产生，不为变化而变化。

## 明确排除

- 不给几个字的短选项分配等大的空洞卡片；用紧凑标签、列表、图例或与说明合并。
- 不让横向短内容只停在上半页，并留下悬空的下半页；优先纵向组织、扩大有叙事作用的图片或重新分组。
- 不把演示中的封面、栏头、页数、网格或图文比例复制为默认模板。
- 不用无角色图片、装饰性 3D 或抽象光效填空。

## 出图前验收

每页至少回答：

1. 这一页唯一最重要的判断是什么，标题是否说出来？
2. 当前结构是否真的表达了内容关系？
3. 是否有容器明显大于其中内容的分量？
4. 是否有整块区域，尤其页面底部，没有承担任务？
5. 大块留白的作用能否用一句话说明？
6. 图片承担什么角色，说明文字是否与它直接对应？
7. 关键对象与关系是否在最终像素中真正居中、对齐？
8. 这一页是否既属于整套系统，又没有机械重复结构？

第 3、4、5 项答不清楚时，不进入正式出图。

## 演示的地位

演示只证明方法在不同内容关系上可以成立，并为视觉质感提供校准证据。它们不定义固定题材、模板或必备页面。具体索引见 [DEMOS.md](DEMOS.md)。
